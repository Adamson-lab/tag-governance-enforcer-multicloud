# ADR-0001: Canonical lowest-common-denominator tag grammar

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** one-way door

## Context
GCP labels allow only lowercase letters, digits, `_` and `-` (63 chars). AWS and Azure accept much more but joins in billing need one spelling.

## Decision
All clouds use lowercase kebab-case keys and lowercase values; owner is a team slug, not an email.

## Alternatives considered
Per-cloud native styles (PascalCase AWS, etc.): rejected, breaks cross-cloud joins and doubles mapping logic. Allow mixed case with case-insensitive match: rejected, GCP cannot store it.

## Consequences
Simple joins and one regex set; some readability loss; aliases map legacy keys.
