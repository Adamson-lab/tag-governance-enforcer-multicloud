# ADR-0002: Three-layer enforcement: prevent, detect, correct

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
No single control covers all resource types: tag-on-create is not supported everywhere.

## Decision
Use preventive controls where native support exists, event+sweep detection everywhere, and correction for deterministic fixes.

## Alternatives considered
Preventive only: rejected, coverage gaps. Detective only: rejected, lets bad data in. Correct-only: rejected, hides root cause.

## Consequences
More moving parts; resilient to any single layer failing.
