# ADR-0003: Cloud-native engines only (Config, Policy, Org Policy)

- **Status:** Superseded by ADR-0004
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
Initial idea: avoid custom code entirely.

## Decision
Use only each cloud's native compliance engine.

## Alternatives considered
n/a

## Consequences
Superseded: three rule dialects, no shared exception model, no cross-cloud score, GCP gaps.
