# ADR-0004: Hub evaluation engine plus native preventive controls

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
Supersedes ADR-0003. Need one decision model, one exception store and one score across clouds.

## Decision
A provider-neutral Python engine in a hub account evaluates adapted events; native controls remain for prevention.

## Alternatives considered
Per-cloud engines: rejected (see 0003). Third-party CSPM only: rejected for cost and exception-model fit, kept as an option for build-vs-buy review.

## Consequences
Custom code to own and test; engine is pure functions so it can move clouds.
