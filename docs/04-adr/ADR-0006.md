# ADR-0006: Do not inherit data-classification

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** one-way door

## Context
A bucket in a public-data RG can hold restricted data.

## Decision
data-classification must be explicit on every resource; inheritance is allowed for owner, cost-center, environment, application, compliance-scope.

## Alternatives considered
Inherit everything: rejected, silently under-classifies data.

## Consequences
More tickets initially; safer posture.
