# ADR-0007: Event-driven detection plus nightly sweep; warm-standby DR

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
Events are fast but can be lost; active/active adds cost with little benefit for a non-blocking control.

## Decision
Events give minutes-level detection; a nightly sweep guarantees convergence; hub runs warm standby in a second region (RTO 60 min).

## Alternatives considered
Sweep only: rejected, slow. Active/active: rejected, cost and complexity vs low outage impact.

## Consequences
Idempotent handlers required.
