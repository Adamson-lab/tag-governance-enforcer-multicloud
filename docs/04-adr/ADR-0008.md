# ADR-0008: Keyless federated identity everywhere

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
Long-lived keys are the top cloud credential risk.

## Decision
GitHub OIDC to each cloud, managed identities/WIF for runtime, TagWriter roles limited to tag APIs, MFA break-glass.

## Alternatives considered
Stored access keys/service-account keys: rejected.

## Consequences
Federation setup effort; no secrets to rotate.
