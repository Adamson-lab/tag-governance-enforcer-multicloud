# ADR-0009: Exceptions are time-boxed waivers stored as data

- **Status:** Accepted
- **Date:** 2026-11-23
- **Deciders:** Architecture board (author: Favour Adamson)
- **Reversibility:** two-way door

## Context
Permanent exceptions rot.

## Decision
Waivers have owner, reason, expiry; engine returns EXEMPT only while valid; expiries reported monthly.

## Alternatives considered
Tag-based exemption (e.g. `exempt=true`): rejected, self-service bypass.

## Consequences
Waiver service needed; audit-friendly.
