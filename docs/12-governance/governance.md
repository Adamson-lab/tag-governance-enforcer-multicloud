# Governance, principles and exceptions
Principles: (1) One standard, many clouds. (2) Prefer prevention, assume leakage. (3) Never guess ownership. (4) Least privilege writers. (5) Everything is code and reviewed. (6) Exceptions expire. (7) Evidence by default.
Decision rights: standard changes via ADR + ARB; waivers approved by Security/GRC (A) with CCoE (R); emergency changes via break-glass with after-the-fact review in 2 business days.
Exception policy: waiver needs owner, reason, expiry <= 90 days (renewable once), recorded in the waiver store.
Review cadence: ARB monthly; standard review quarterly using drift and false-positive metrics.
