# Executive brief
**Problem:** cloud costs and risks cannot be tied to owners. **Decision needed:** fund Wave 0-1. **Options:** do nothing (continued unallocated spend), buy a third-party CSPM only, build the hub enforcer with native controls (recommended), or an ambitious auto-everything programme (rejected: risk). **Cost:** run cost under $100/month at 150k resources (modelled); build effort in Waves 0-1 is a team estimate to be confirmed. **Risk:** wrong auto-fixes (mitigated by deterministic-only rule). **Value:** attributable spend and auditable ownership.
## Executive FAQ
1. *Will it delete anything?* No. Expired sandbox assets are stopped and snapshotted only after approval (ADR-0010). 2. *Can it break production?* It never changes anything but tags; denies roll out Audit -> Deny by wave. 3. *Does it save money?* It makes spend attributable; savings depend on owners acting (scenarios in the cost model). 4. *Who owns exceptions?* Security/GRC approves, CCoE operates. 5. *What if AWS is down?* Detection pauses, workloads unaffected; warm standby and nightly sweep recover. 6. *Vendor lock-in?* Neutral engine and standard; thin handlers per cloud. 7. *Evidence for auditors?* Immutable audit log plus scorecards.
